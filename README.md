## What I work on

My work sits at the intersection of autonomous agents, memory, retrieval, and production data infrastructure.

- **Agent memory:** episodic, semantic, and procedural memory that gives agents useful context without wasting tokens.
- **Retrieval systems:** methods for finding conceptual gaps and measuring whether retrieved context actually covers a question.
- **AI-ready data:** dependable extraction pipelines for RAG, model training, research, and market intelligence.
- **Agent tooling:** MCP integrations and automation systems that connect models to real business tools.
- **Efficient AI:** practical ways to run capable systems under compute, memory, and latency constraints.
